# Project Context Sync

For a pause, save branch/commit, remaining acceptance criteria, verification
results, blockers, and next action under the repository's Git directory.
Update the same short note instead of appending a history.

Put durable technical decisions in the relevant feature document or ADR.
Update PR status from GitHub evidence. Use an external tracker only when the
user requested that integration; do not recreate CONTEXT.md or synchronize
Notion by default. Keep secrets, raw logs, and personal data out of handoffs.
